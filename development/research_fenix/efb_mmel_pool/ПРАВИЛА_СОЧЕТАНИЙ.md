# FAA MMEL Combination Rules **Combination criterion:** The selected failures must not violate the MMEL requirements for the operability of other equipment or the permissible number of idle units. Suitable alternative lines are taken into account together with the conditions; by a separate decision of the user, options with unpressurized flight are excluded.

The whole set of 1-3 different IDs is evaluated. Repeating an ID is not a second failure. If there is a suitable line for each affected item, the result is “No MMEL ban was found”. This is not an absolute dispatch relief: the conditions of the selected line are retained as a result.

All 53 single failures, 1,378 pairs and 23,426 triples were checked. **89 prohibited pairs** and **2 additional minimum prohibited threes** were found, each pair being tested separately.

Machine rules:[rules.json](rules.json). Full reasons:[forbidden_combinations.json](forbidden_combinations.json). Tables:[pair](forbidden_pairs.csv), [triplet](forbidden_triples.csv).

# Considered exceptions

- CPC1 + CPC2 is excluded: the common line 21-31-01 that allowed this pair requires unpressurized flight and is removed by the user. Individual CPCs remain in the directory. FCU + CPC is also prohibited: the FCU clause requires both CPCs to be serviceable.
- AP1 + AP2: 22-10-01 allows both with route restrictions, lows and crew loads.
- Both APU circuits: 26-13-01 allow for non-use of the APU and limitations of the selected line.
- Both TAT heaters: 30-31-05 allows without ETOPS more than 120 minutes, visible moisture and icing.
- Both DCDU: 46-21-02 allows for alternative procedures or no need for use.
- SFCC2 FLAP + SFCC2 SLAT: there is no requirement to save another SFCC2 channel in the counted lines; the requirements for SFCC1 and other systems remain.

# Explicit boundaries of interpretation

- For static heaters, “operative units” are treated as other CAPT/F/O/STBY positions. This leads to these connections with heaters of other positions. The string of one STBY does not contain such a condition.
- Separately selected AUTO/BRK + wheel brake is prohibited by 32-42-04(b), requiring unaffected normal braking. The wheel brake at 32-42-01(i) has already recorded the AUTO/BRK state as a consequence: it does not need to be separately activated as a second independent defect.
- No additional waivers are inferred from the alleged behavior of FAC, FWC, SDAC, CFDS, power supply or hydraulic systems. For example, the failure of the yellow electric pump does not equate to the failure of the entire yellow system.
- Weather, route, timing and technical actions remain the terms of the cards; they are not automatic filters of the set.

# Minimum prohibited threes

- M257 (TAT CAPT sensor heating) + M267 (Static STBY port heating - left) + M268 (Static STBY port heating - right) - 30-31-03.
- M258 (TAT F/O sensor heating) + M267 (Static STBY port heating - left) + M268 (Static STBY port heating - right) - 30-31-03.
