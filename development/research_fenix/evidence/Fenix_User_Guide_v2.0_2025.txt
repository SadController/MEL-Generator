1.0 Introduction
1.1 The Fenix Airbus A320 family
Welcome aboard the Fenix A320 family. We’ve painstakingly modelled your aircraft so it faithfully 
replicates an Airbus A320 CEO family (Current Engine Option) with EIS2 (Electronic Instrumentation System, 
2nd generation) equipment.
The Airbus A320 family are narrow-body airliners developed and produced by Airbus with parts manufactured 
across Europe. The aircraft was launched in March 1984, first flew on the 22nd February 1987 and was introduced 
into service in April 1988 by Air France.
With a versatile cabin, the A320 can carry up to 180 passengers and 16.6 tonnes of cargo with a range up to 
3,300nm. The aircraft operates up to 39,000ft at up to Mach 0.82 with a maximum takeoff weight of 78 tonnes.
The Fenix Airbus A320 family stands 38’ 7” tall, has a wingspan of 111‘ 11”, with a length between 111‘ and 146‘ 
depending on the variant, and has a fuselage 13‘ wide.
There are nearly 400 airline operators of the A320 family globally, each able to customise the configuration of 
the aircraft. Fenix have provided the ability for you to customise your aircraft individually via settings in the EFB 
or based on the livery installed.

You can make use of either SayIntentions, BeyondATC or the Hoppie ACARS service and we have fully integrated 
it into the MCDU as in the real aircraft. To make use of the Hoppie service you’ll need to register an account by 
visiting https://www.hoppie.nl/acars/system/register.html . Once created, add your ACARS Login Code to this 
field to enable the ATC Comm menu in the MCDU. 
In the case of using SayIntentions or BeyondATC, the API key is automatically read for you from the app.
Note: If the sim is running when you add the code, the changes will take effect the next time you load the 
aircraft in the simulator.

We acknowledge that there are many different sim setups in use across the sim community, with varying budgets 
and configurations leading to different performance experienced when using MSFS. To ensure that different

This setting may help with serious performance degradation issues or graphical glitches.

3.1 Controls calibration – Thrust, Sidestick & Flaps
Ahead of your first flight, you will need to calibrate your thrust levers if you are using one. The MCDU page is at 
MENU > CONFIG > CONTROLS CONFIG.
Choose the Calibrate option and the page will guide you where to set the thrust levers to set each detent.
When you have completed all of the steps choose STORE CALIBRATION to complete the process.
Notes:
1.) If your thrust lever doesn’t have positions for reverse or idle reverse, leave the thrust lever in idle and   
progress past those steps in the calibration process by choosing NEXT STEP.
2.) If you are using the Thrustmaster Airbus TCA controller, see the FAQ section of this document for      
mapping controls in MSFS.
If you use an external controller for flap settings you can calibrate this in the same MCDU page by using the 
right arrow.

4.0 Electronic Flight Bag (EFB)
4.1 The Fenix EFB
An electronic flight bag (EFB) is an electronic information management device that helps flight crews perform 
flight management tasks more easily and efficiently with less reliance on paper materials. The EFB consolidates 
important information like navigational charts, performance calculators, checklists and other documents. The EFB 
supports inputs from both physical keyboard and virtual on-screen keyboard. In MSFS 2024 the EFB is also 
accessible as an app via the native virtual tablet.
The Fenix A320 family ships with a comprehensive set of apps that we fully expect to mature and increase in 
functionality in future updates.
4.2 EFB Applications
There are several applications installed on the Fenix EFB to help plan and carry out your flight:
•
Fenix App – Flight information, ground services, aircraft mass & balance, panel states and sim settings
•
Departure Performance – Calculate departure performance
•
Arrival Performance – Calculate arrival performance
•
Charts – Review departure, enroute and arrival charts. Supports both in-sim LIDO charts (MSFS 2024 
ONLY) or Navigraph (requires Navigraph Charts subscription) – includes integration with simbrief.com. For 
users without a subscription, you can use the route map feature.
•
Pilot Brief – Operational flight plan, weather briefing, NOTAMs, checklist, QRH and other 
documentation
•
Failures – Manage aircraft system failures. Manually enable, disable or arm failures based on 
specified conditions
•
Settings – Adjust EFB settings, brightness, Simbrief username, printing features or reboot the EFB.
•
Web MCDU – Only available if using the EFB on external device or via browser on your PC
A handy app switcher is also available via the   
   symbol at the top of the screen.

4.3 Using the EFB on an external device or web browser
You can connect to the EFB via your internet browser or via external device like iPad provided the device is on the 
same network as the computer running MSFS. Both options also gives you access to the Web MCDU.
4.3.1 Access via external device
With the simulator running and the Fenix A320 app running, navigate to http://<LOCAL IP>:8083 (example: 
http://192.168.1.60:8083). Please ensure your firewall allows port 8083 to be used across the local network. 
Find more information in this linking your tablet to the EFB knowledge base article.
To find out your IP address of the computer running MSFS, search for Network Status in the Windows Search, 
choose Properties next to your active connection then read the IP address shown as IPv4 address.
4.3.2 Access via browser on your PC
To run the EFB on the same machine as your sim you can connect using http://localhost:8083.
Note, when viewing on a browser or external device, to return to the Home Screen of the EFB use the grey 
‘home button’ shown in the bottom left-hand corner of the EFB screen. This button can be moved by dragging it 
to your desired location.
4.4 Web MCDU
Accessing your EFB from external device or your internet browser using guide mentioned above gives you option 
to use web version of the MCDU by clicking the MCDU app icon. Once opened you will be prompted to select if 
you want to control the left or right MCDU.

4.4 Removing the EFB
If you’d like to fly without the EFB displayed in the sim you can simply turn it off by using a click spot by the 
handheld cockpit microphone which is below the EFB. While using the EFB, don’t forget to keep it charged, add
the charging cable via the click spot near the home button.
4.5 Authorising Navigraph
On first use, you’ll need to give permission for the EFB to receive information from your Navigraph account. 
Simply open the Navigraph app on your EFB in the simulator, scan the QR code or open 
https://navigraph.com/code and enter the code shown on your EFB screen. Follow the instructions on screen to 
grant access.

5.0 Fenix app
You can use the EFB to load passengers, cargo and fuel onto the aircraft for your flight and we also offer seamless 
integration with Simbrief and GSX to make planning and loading even easier and immersive. The MY FLIGHT tab 
contains information about your current flight, weather information and information about your route.
5.0.1 Using Simbrief.com
We have integrated Simbrief to allow you to load flight plans and data directly into the EFB and MCDU when you
have created a flight plan in their interface. In order to use this service, you will need to create an account at 
Simbrief.com and then enter your username or pilot ID into the EFB settings app.
When entered, you’ll be able to use the REQUEST INIT functionality on the INIT and SEC-FPLN pages in the 
MCDU.
   
1. Add your Simbrief username to the settings app in EFB
2. Plan your flight with Simbrief as usual. Profiles for each of our airframes is available via Simbrief 
in the Variant or Airframe tab 
3. Load MSFS and the Fenix aircraft at your chosen departure airfield
4. Open the Fenix app and choose IMPORT FLIGHT FROM SIMBRIEF on the MY FLIGHT tab
5. In the MASS AND BALANCE tab, select LOAD AIRCRAFT and choose how quickly you’d like
the loading to take or if you would like to use GSX.
6. Preliminary loadsheets are delivered 30 minutes before departure and can be accessed via the MCDU > 
ATSU > AOC MENU > RCVD MSGS
7. Once loading is finished, you can use the SEND TO MCDU button to send your final weight and CG value to 
the Init B page of the MCDU.

6.0 Performance Calculations
The EFB has performance applications that will help you to calculate the performance of the aircraft during 
departure and arrival. Simply populate the data required to perform the calculations. 
6.1 Departure performance
Input the ICAO of the airport, select the runway and its condition. Take off weight (TOW) and Take Off CG% 
(MACTOW) can be populated from either preliminary or final loadsheet by clicking the SYNC LOADSHEET 
button. METAR information can be obtained and populated by clicking the SYNC LIVE WX button. Calculated 
performance can be transferred to MCDU by clicking the SEND TO MCDU button.
6.2 Arrival performance
Input the ICAO of the airport, select the runway, its condition and landing weight of the aircraft. METAR 
information can be obtained and populated by clicking the REFRESH METAR and APPLY METAR buttons. If 
prompted to perform LDG Distance Procedure you can select the type of failure in the calculator to ensure the 
impact to performance taken into account.

7.0 Charts app
Our Charts app automatically syncs with your imported Simbrief plan from the Fenix EFB app and fills the ICAO 
code fields for your departure, arrival and alternate airports. You can press the SYNC ROUTE button to do the 
same. If you are not using Simbrief you can enter ICAO codes manually. The app supports both JEPPESEN charts 
provided by Navigraph (requires subscription) as well as LIDO charts provided by the sim (available in MSFS 2024 
in-sim only). If neither are available, the app can be used to follow your route and progress on map.
You can click the star icon next to the chart name for easier and quicker access to selected charts via the Starred 
tab. When importing flight via Simbrief, your Approach, Arrival as well as selected ground charts will be 
automatically starred.

11.0 Walkaround mode (MSFS 2024 only)
With the introduction of the native compatibility for MSFS 2024, an extensive support of the sim walkaround 
function has been added. 
To enter the walkaround mode, you can either use the sim key bind, or by clicking the high visibility vest hanged 
in the cockpit.
To exit the walkaround mode, you can click the coat hanger where the vest was hanging or by clicking the pilot 
seat.
You can move freely around and inside the aircraft and interact with various components such as doors, stairs, 
engines and various service hatches and controls like fuelling panel, cargo door controls and main gear door 
controls with all the associated system logic.
To operate the doors and controls, simply follow steps listed on the decals placed near the controls.
Note: For full functionality of aircraft systems, it is recommended to exit and re-enter the walkaround mode 
once to allow the aircraft systems to fully initialise.
Note: When spawning at a gate, MSFS2024 will force the avatar to spawn under the aircraft. This is out of our 
control but will only happen once, before the normal spawn point (standing in the cockpit) is used. You can 
check other walkaround mode quirks in the FS2024 Walkaround Quirks article.

12.0 Company Messages
From time to time the airline operations team will send messages to the aircraft ATSU AOC function as 
follows:
•
Loadsheets– The preliminary loadsheet is sent around 30 minutes prior to the departure time. 
The final loadsheet is available once boarding is completed.
•
Departure time – The on-time performance is monitored and a confirmation of the aircraft’s departure 
time compared to schedule is commutated to the crew. If the aircraft departs late the operations team 
will request an ADC Delay code. You can find a list of the appropriate codes on the home screen of the 
EFB by selecting DELAY ALLOCATION CARD

14.0 Frequently Asked Questions (FAQs)
Q: I’m encountering Login Failed – License already activated on different machine error when starting the Fenix
application
 A: Please follow the steps in the How do I reset my Fenix A32X License/Activation? article.
Q: My thrust control ‘spikes’ or behaves strangely
A: We’ve included a calibration tool to help you ensure that your thrust controls behave as expected. It’s 
available in the MCDU Configuration menu – make sure to calibrate before you fly.
Q: I’m using the Thrustmaster Airbus TCA controller and throttle quadrant but can’t map the controls 
properly
A: MSFS has multiple control binds for throttle controls. For the TCA controller you need to map your controls
to ‘Throttle 1 Axis’ & ‘Throttle 2 Axis’.
For further information and video guides, please visit following Knowledge Base Articles
Fenix A320 Flight Control Calibration
How to setup your Thrustmaster TCA Throttle
Flaps are unresponsive / Flaps Calibration 
Q: My autopilot randomly disconnects during a flight
A:  Make sure you don’t have any conflicting bindings and that you have added deadzone to your flight controls
axes. You can find more detailed information in this Uncommanded Autopilot Disconnects article.
Q: Some key bindings are not working
A: Not every key binding in MSFS2020 will work with the Fenix A320 due to its externalised architecture. We 
have created a set of default bindings for certain controls that is available in the Useful default keybinds 
article.
Q: The Ram Air Turbine (RAT) comes out when slewing the aircraft
A: This happens from time to time in MSFS 2020 so we recommend avoiding use of the slew function where
possible. To avoid ‘spawning’ on occupied stands you can check whether the stand is available in a mapping tool
i.e. Volanta.
