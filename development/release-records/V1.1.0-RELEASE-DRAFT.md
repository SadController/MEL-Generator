# MEL Generator v1.1.0 release draft

Windows x64 installer for Microsoft Flight Simulator 2024 and Fenix A319, A320,
and A321. The generator uses 53 reviewed failures from FAA A320 MMEL Revision 32
(30 July 2025).

## What's new

- Generate a briefing with 1–3 compatible failures and activate them in the
  Fenix aircraft automatically or with a button on the briefing page.
- Deactivate the failures activated from the current briefing with one button;
  failures that were active beforehand are preserved.
- See simulator and aircraft-adapter readiness through the two header indicators.
- Configure automatic activation, update checks, and optional diagnostic logs.
  Check for a newer stable version and download it from within the app.
- Get actionable error messages for source, simulator, activation, and update
  problems.

The installer is for the current Windows user and offers an optional desktop
shortcut. This release is unsigned and has no portable edition.

## Review before publication

The 1.1.0 installer and packaged app passed local build and QA. GitHub update
discovery, installer download, and checksum verification were tested against the
beta release. An installed older-to-newer upgrade through the stable release
channel, including the final restart and failure recovery, is not yet verified.
The release must remain a draft until the owner reviews and publishes it.
